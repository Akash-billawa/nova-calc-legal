We're here to help

Reach out for help with NovaCalc, including app questions, download issues, bug reports, feature requests, website feedback, privacy questions, and store listing concerns. Clear details help support understand what happened, reproduce the issue, and reply with the most useful next step.

Support email: novacalc.help@gmail.com

Support Channels

  • For general help, send a short description of what you were trying to calculate and where you got stuck.
  • For bug reports, include the tool name, entered values, expected result, actual result, and whether the issue repeats.
  • For feature requests, explain the calculation problem, the missing inputs, and how the result should be used.
  • For download questions, mention whether you used Google Play, GitHub releases, Windows, Linux .deb, or Linux .rpm.
  • For privacy or terms questions, include the page or policy section you want clarified.

What to include in a support email

  • App version, platform, and operating system if you know them.
  • The exact page or tool you were using, such as Calculator, Converter, Graph, History, Settings, or a named calculator.
  • The values you entered and the result you expected to see.
  • A short note about whether the issue happened once or happens every time.
  • Screenshots or screen recordings when they make the problem easier to understand.
  • Any accessibility, language, layout, or device-size problem that affects the way you use the app.

Bug reports

Report calculation errors, broken navigation, display problems, history issues, download problems, crashes, or any behavior that feels different from what the tool name or inputs suggest.

Feature ideas

Suggest new calculators, additional units, better defaults, result explanations, export formats, shortcut behavior, or workflow changes that would make repeated calculations faster.

Policy questions

Ask for clarification about the privacy policy, terms of service, local history behavior, permissions, platform downloads, or how support messages are handled after you contact NovaCalc.

Before sending

  • Check the Features page if you want to confirm whether a tool already exists.
  • Check Privacy if your question is about local data, preferences, or policy language.
  • Check Terms if your question is about app usage, availability, or responsibility for results.
  • Use one email per issue when possible so each request can be tracked clearly.

Support quality

  • Reports with exact inputs, expected results, screenshots, and platform details are easier to reproduce and prioritize.
  • Feature requests are most useful when they describe the real calculation problem, not only the name of a missing tool.
  • Download issues should mention the selected platform and whether the user started from Google Play, GitHub, or the website.
  • Privacy and terms questions should point to the relevant page section so the reply can address the exact concern.
